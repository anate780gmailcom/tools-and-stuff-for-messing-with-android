# 🧠 DOCTRINE

This project exists to learn by doing.

## Principles

1. Understand before automate
2. Build tools you actually use
3. Keep things simple and readable
4. Separate core tools from experiments
5. Document everything

## Structure Philosophy

- Core tools → reliable, repeatable
- Extras → experimental, situational
- Notes → future improvements

## Goal

Not just to scan networks,
but to understand what is happening and why.

## Long Term Vision

- Expand scanner capabilities
- Add logging and parsing
- Integrate with other tools
- Build a full mobile security lab
